# 📥 How to Install EcoTrace

Since EcoTrace is an open-source browser extension and not yet hosted on the Chrome Web Store, you can easily install it manually in just a few steps.

---

## 🛠️ Option 1: Fast Installation via ZIP Release (Recommended)

1. Download the latest `EcoTrace.zip` from our [Releases](https://github.com/Maxation/EcoTrace/releases) page.
2. Unzip (extract) the downloaded ZIP file into a folder on your computer.
3. Open your browser (Chrome, Brave, or Edge) and go to the Extensions page:
   * In Chrome/Brave, type `chrome://extensions/` in the address bar.
4. In the top-right corner, toggle the **"Developer mode"** (Entwicklermodus) switch to **ON**.
5. In the top-left corner, click the **"Load unpacked"** (Entpackte Erweiterung laden) button.
6. Select the folder where you unzipped the EcoTrace files.
7. 🎉 **Done!** The EcoTrace icon will appear in your browser bar and activate automatically on Amazon product pages.
